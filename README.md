# Project Details

In this notebook I am cleaning and analyzing datasets released by Instacart Via Kaggle in 2017. I have two questions I want to answer and plot with the provided data:

1. How many items to customers typically order in one order?
2. What are the top 20 most reordered products?

This analysis will also give us more insight into shopping habbits of Instacart users.
